# `public/media/` — page artwork and footage

Every content page carries one image and can carry one video. Nothing in here
is a photograph, because the client has not supplied any; the site draws its
own plates instead of showing stock pictures of somebody else's newsroom.

## Images

`sections/*.svg` and `services/*.svg` are generated by
[`scripts/generate-media.mjs`](../../scripts/generate-media.mjs):

```bash
node scripts/generate-media.mjs   # or: npm run media
```

They are deterministic — the same slug always produces the same file — so
re-running the script never churns the diff.

**To use a real photograph instead:** drop a file with the same base name and a
16:9 box (1200 × 675 or larger) into the same folder, then point the page's
`media.image` at it in `src/content/services.{ne,en}.ts` or
`src/content/{ne,en}.ts`. Update `alt`, `width`, and `height` at the same time —
the dimensions are declared so the browser reserves the box and the page does
not shift while the file loads. `alt` is not decoration: it is read aloud, and
it is one of the few places a page can describe its subject in words.

Prefer AVIF or WebP for photographs. Remove the generated `.svg` it replaces so
two files do not describe the same page.

## Video

No footage has been supplied, so every page's `media.video` is currently
absent and `VideoBlock` renders nothing at all — a page never claims a film it
does not have.

To light one up, add a `video` object beside the page's `image`:

```ts
media: {
  image: { src: "/media/services/documentary.svg", alt: "…", width: 1200, height: 675 },
  video: {
    url: "https://www.youtube.com/watch?v=XXXXXXXXXXX",
    title: "Documentary showreel",
    description: "Two minutes of field and interview work from 2026.",
    thumbnail: "/media/video/documentary-poster.jpg",
    uploadDate: "2026-02-01",
    duration: "PT2M14S",
  },
}
```

That is the whole change. The page gains a player, and `lib/schema.ts` adds the
matching `VideoObject` node to the page's structured data at the same time, so
the film becomes eligible for a video result in search.

- A YouTube watch URL is rewritten to `youtube-nocookie.com` automatically; pass
  `embedUrl` to override.
- A self-hosted file (`/media/video/*.mp4`) renders in a native `<video>`
  element instead. Keep it under a few megabytes, or host it.
- `thumbnail` is required — the poster frame is what stands in before the player
  loads, and `VideoObject.thumbnailUrl` is required for video rich results.
- `uploadDate` and `duration` are optional but both feed the rich result; the
  duration is ISO 8601 (`PT2M14S` = 2 minutes 14 seconds).
